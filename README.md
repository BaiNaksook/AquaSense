# SaltSense

**Smart Salt Farm Water Level & Salinity Monitoring System**

ระบบตรวจวัดระดับน้ำและความเค็ม เพื่อการบริหารจัดการนาเกลือ — เว็บแดชบอร์ด (PWA) แสดงระดับน้ำแบบเรียลไทม์จาก ESP32 พร้อมพยากรณ์อากาศและคำแนะนำสำหรับชาวนาเกลือ

## การทำงาน

```
ESP32 + อัลตราโซนิก ──MQTT──► HiveMQ Cloud ──WebSocket──► เว็บ (React)
                                                          ├─► Supabase (water_readings, alert_history)
                                                          └─◄ Open-Meteo / กรมอุตุฯ (พยากรณ์อากาศ)
```

- ค่าที่วัดคือ **ระยะจากเซ็นเซอร์ถึงผิวน้ำ** (ระยะน้อย = น้ำสูง)
  - ≤ 32.4 ซม. อันตราย · ≤ 45 ซม. เฝ้าระวัง · > 45 ซม. ปลอดภัย (ตรงกับ ESP32)
- ไม่มีข้อมูลเกิน 20 วินาที → แสดง "เซ็นเซอร์ขาดการติดต่อ" และค่าเป็นสีเทา
- เว็บ **อ่านข้อมูลอย่างเดียว** ไม่ส่งคำสั่งเปิด/ปิดไปที่ ESP32

## พยากรณ์อากาศสำหรับนาเกลือ (`src/weather.js`)

ดึงพยากรณ์ 7 วันจาก [Open-Meteo](https://open-meteo.com) (ฟรี ไม่ต้องใช้ key) และ
ถ้าตั้ง `VITE_TMD_TOKEN` จะดึงคำพยากรณ์ของกรมอุตุนิยมวิทยามาเสริม ระบบรีเฟรชทุก 30 นาที
และเก็บข้อมูลล่าสุดไว้ใช้ตอนออฟไลน์

| เงื่อนไข | ระดับ | คำแนะนำ |
|---|---|---|
| ฟ้าคะนอง หรือ ลมแรง + มีฝน | อันตราย | เก็บเกลือขึ้นกอง ยึดผ้าใบ ตรวจคันนา |
| ฝน ≥ 10 มม. | อันตราย | คลุมกองเกลือ งดไขน้ำเชื้อเข้านาปลง |
| โอกาสฝน ≥ 60% หรือ ≥ 2 มม. | อันตราย | รื้อเกลือขึ้นกองและคลุมไว้ก่อน |
| โอกาสฝน ≥ 40% หรือ ≥ 1 มม. | เฝ้าระวัง | เตรียมผ้าใบคลุมกองเกลือ |
| ลม ≥ 40 กม./ชม. (กระโชก ≥ 50) | เฝ้าระวัง | ยึดผ้าใบ ระวังคลื่นกัดคันนา |
| ET0 ≥ 4.5 มม., ฝน < 20%, ความชื้น < 70% | เหมาะ | เหมาะตากเกลือ / รื้อเกลือ |

เกณฑ์ทั้งหมดเป็นค่าประมาณเชิงปฏิบัติ ปรับได้ที่ต้นไฟล์ `src/weather.js`
หน้าแรกจะรวมระดับน้ำกับพยากรณ์ เช่น น้ำสูง + ฝนกำลังมา → "ควรระบายน้ำออกก่อน"

## เริ่มใช้งาน

```bash
cp .env.example .env         # แล้วแก้ค่าให้ถูกต้อง
npm install
npm run dev                  # พัฒนา
npm run build                # build → dist/
```

## เสียงพูด (ปุ่ม "กดฟังเสียง")

ใช้**เสียงคนจริงที่อัดไว้**ก่อน ประโยคไหนยังไม่มีไฟล์จะใช้เสียงอ่านอัตโนมัติของเครื่องแทน
บทอัดเสียงและวิธีทำอยู่ที่ [docs/voice-recording.md](docs/voice-recording.md)

```bash
npm run voice:process   # ประมวลผลไฟล์ใน voice-raw/ → public/voice/*.mp3 (ต้องมี ffmpeg)
npm run voice:script    # สร้างบทอัดเสียงใหม่ หลังแก้ src/voiceClips.js
```

## Deploy บน Vercel

ตั้งค่าไว้แล้วใน `vercel.json` (Vite → `dist/`, service worker ไม่ถูก cache ค้าง)

- **ผ่าน CLI:** `npx vercel` (ลิงก์ทดลอง) → `npx vercel --prod` (เว็บจริง)
- **ผ่าน GitHub:** vercel.com → Add New → Project → เลือก repo นี้ → Deploy
  ทุกครั้งที่ push เข้า `main` จะ deploy อัตโนมัติ และทุก branch จะได้ลิงก์ preview

ตั้ง Environment Variables (ถ้ามี) ที่ Project → Settings → Environment Variables ตาม `.env.example`
แล้ว Redeploy เพราะค่า `VITE_*` ถูกฝังตอน build

## โครงสร้าง

- `src/App.jsx` — หน้าเว็บหลัก, MQTT, สถานะ, กราฟ, ประวัติแจ้งเตือน
- `src/weather.js` — ดึงพยากรณ์ + ตรรกะคำแนะนำนาเกลือ
- `src/WeatherPanel.jsx` — การ์ดพยากรณ์อากาศ
- `src/index.css` — design tokens (โหมดสว่าง/มืด)
- `public/sw-push.js`, `supabase/functions/send-push` — Web Push (ยังไม่ได้เชื่อมกับหน้าเว็บ)
