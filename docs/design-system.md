# SaltSense design system

ทิศทาง: **"ลานเกลือกลางแดด"** — เครื่องมือของชาวนาเกลือ ไม่ใช่แดชบอร์ด SaaS
ผู้ใช้หลักอายุ 45–65 ปี ใช้มือถือ Android ราคาประหยัดกลางแดดจัด บางคนอ่านหนังสือไม่คล่อง

## หลัก 6 ข้อ
1. **ปกติ = สงบ, ผิดปกติ = มีสี** (แนว High-Performance HMI) — สถานะปกติใช้พื้น `--surface` เส้นขอบเทา ตัวหนังสือ `--fg`
   สี `--warning` / `--danger` ใช้เฉพาะเมื่อต้องลงมือทำ อันตรายใช้ **พื้นแดงทึบ ตัวขาว** แบบป้ายเตือน
2. **สถานะต้องมี 3 อย่างพร้อมกันเสมอ:** รูปทรง/ไอคอน + คำ + สี (ห้ามสื่อด้วยสีอย่างเดียว)
3. **คำก่อน ตัวเลขทีหลัง:** บรรทัดแรกบอกว่าต้องทำอะไร ตัวเลขเป็นข้อมูลประกอบ และต้องเทียบกับเกณฑ์เสมอ
   ("อีก 12 ซม. ถึงขีดอันตราย" ไม่ใช่ "ระยะ 44 ซม.")
4. **ไม่มีของตกแต่ง:** ห้าม gradient พื้นหลัง, glassmorphism/blur, เงาเรืองสี, แถบสีซ้ายการ์ด, pill badge ทุกที่,
   ไอคอนหน้าทุกบรรทัด, แอนิเมชันวนไม่หยุด (ยกเว้นสถานะอันตราย)
5. **อ่านได้กลางแดด:** ตัวหนังสือเนื้อหา ≥ 18px (1.125rem), ป้าย ≥ 16px, ข้อความรอง ≥ 15px, น้ำหนัก ≥ 400
   ปุ่ม/พื้นที่แตะ ≥ 48px (ปุ่มหลัก 56px)
6. **ใช้คำของชาวนาเกลือ:** กล่องวัดน้ำ, ในนา, นาปลง, น้ำเชื้อ, รื้อเกลือ, คันนา, น้ำขม, ดีกรี (แทน °Bé), เน็ต
   ห้าม: เซ็นเซอร์ (ในหน้าชาวนา), ออนไลน์, เรียลไทม์, ระเหย, ตกผลึก, ดำเนินการ, บริหารจัดการ, ภาษาอังกฤษ

## Token (อยู่ใน `src/index.css` — ใช้ผ่าน `var(--x)` เท่านั้น ห้ามใส่สี hex ตรงๆ ในคอมโพเนนต์)
| token | บทบาท |
|---|---|
| `--bg` | พื้นหลังหน้า (ลานเกลือ) |
| `--surface` / `--surface-2` | พื้นการ์ด / พื้นรอง แถบ ช่องข้อมูล |
| `--fg` / `--muted` | ตัวหนังสือหลัก (ดินนา) / รอง — muted ผ่าน 7:1 บน surface |
| `--border` / `--border-strong` | เส้นแบ่ง / ขอบการ์ดและกรอบที่ต้องเห็นกลางแดด |
| `--primary` | น้ำเค็ม — ลิงก์ ปุ่มรอง เส้นกราฟ น้ำในภาพ |
| `--accent` | ชมพูนาเกลือ — แบรนด์ และช่วง "พร้อมเก็บ" เท่านั้น ห้ามใช้เป็นสีเตือน |
| `--safe` / `--warning` / `--danger` | สถานะ (ตัวหนังสือผ่าน 4.5:1 ทั้งสองธีม) |
| `--on-danger` | ตัวหนังสือบนพื้น `--danger` |
| `--radius` (10px) / `--radius-lg` (14px) | มุมโค้ง — ห้ามเกิน 14px |
| `--space-1..7` | 4 / 8 / 12 / 16 / 24 / 32 / 48 px |

## ตัวอักษร
- `font-family: var(--font-ui)` = Inter (ตัวเลข/ละติน) + **Noto Sans Thai Looped** (ไทยแบบมีหัว) — ตั้งไว้ที่ body แล้ว
- ตัวเลขค่าวัด: class `.num` (tabular-nums, line-height 1)
- สเกล: `--fs-hero` 3rem · `--fs-title` 1.5rem · `--fs-lead` 1.25rem · `--fs-body` 1.125rem · `--fs-label` 1rem · `--fs-small` .9375rem
- ห้าม `letter-spacing` กับข้อความไทย, ห้าม `text-transform`/ตัวเอียงกับไทย, line-height ข้อความไทย ≥ 1.4

## การเคลื่อนไหว
- ไม่ใช้ framer-motion (ถูกถอดออกแล้ว) ใช้ CSS เท่านั้น
- เปลี่ยนค่า: 180ms `var(--ease)` · กดปุ่ม: `:active { transform: scale(.97) }`
- `animation: … infinite` ได้เฉพาะสถานะอันตราย และต้องปิดใน `prefers-reduced-motion`

## คอมโพเนนต์ร่วม
- `src/water.js` — `RED_MAX`, `YELLOW_MAX`, `getWaterStatus`, `marginToDanger`, `WATER_STATUS`, `ago`, `clockTime`
- `src/icons/SaltIcons.jsx` — ไอคอนเฉพาะนาเกลือ (props เหมือน lucide: `className`, `aria-hidden`)
- `src/weather.js`, `src/salinity.js` — ข้อมูล/ตรรกะพยากรณ์ (ห้ามเปลี่ยน signature ของฟังก์ชันที่ export)
- CSS ของแต่ละหน้าอยู่ใน `src/styles/<ชื่อ>.css` และ import ในคอมโพเนนต์นั้น ใช้ prefix class ของตัวเอง
- คลาสพื้นฐานใน index.css: `.panel` (การ์ดสงบ), `.btn`, `.btn-primary`, `.btn-quiet`, `.num`, `.muted`, `.section-title`, `.tag`
